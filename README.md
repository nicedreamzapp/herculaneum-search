# Searching the Herculaneum Scrolls

A narrated two-minute video and an interactive 3D page showing a search for ink on the carbonized Herculaneum scrolls, buried by Vesuvius in 79 AD.

**Watch and explore:** https://nicedreamzapp.github.io/herculaneum-search/

## What's here

- A 3D viewer of the scanned scroll surfaces with the ink predictions laid on top
- The candidate finds, each one shown next to how many ink models agreed on it
- The method and an honest disclaimer: these are candidate letters, not translations
- Shots marked "AI illustration" are artistic reconstructions, not scan data
